# Student Performance Analysis

This is my first data analysis project using Python and Pandas.  
The goal of this project is to analyze student performance and explore how factors such as study hours and attendance relate to exam scores.

## Dataset

The dataset contains information about 10 students, including:

- Student name
- Major
- Study hours
- Attendance
- Sleep hours
- Exam score

## Questions Explored

In this project, I used Pandas to answer questions such as:

- Who had the highest exam score?
- What was the average exam score?
- Which students scored above 85?
- What was the average exam score for each major?
- How are study hours related to exam scores?
- How is attendance related to exam scores?

## Pandas Skills Used

- Creating DataFrames
- Selecting columns
- Filtering rows
- Sorting with `sort_values()`
- Grouping data with `groupby()`
- Calculating averages with `mean()`
- Creating new columns with `apply()`
- Calculating correlations with `corr()`

## Data Visualization

I used Matplotlib to create scatter plots comparing:

- Study Hours vs. Exam Score
- Attendance vs. Exam Score

These visualizations helped explore relationships between student habits and academic performance.
